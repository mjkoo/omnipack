## REMOVED Requirements

### Requirement: Quiver discovery accounts for the complete configured catalog

**Reason**: Quiver generation no longer looks repositories up, resolves releases, inspects APKs, applies per-project policy or skips; one generator for every source replaces it.

**Migration**: Replaced by "Discovery reads each source's upstream list" and "Each listed project becomes a minimal Obtainium entry" in source-generation; per-app settings move to overlay records and categories to the category map.
